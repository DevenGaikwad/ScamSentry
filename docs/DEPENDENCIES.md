The archived fallback remains fully preserved. A fresh archived core build passed five JUnit methods on Gradle 9.3.1/JDK 21 before changing the toolchain. The v2 group uses AGP 9.5.1 / Gradle 9.6.0, Kotlin/Compose compiler 2.4.21, KSP 2.3.10, BOM 2026.09.00, Material 3 1.4.0, Activity 1.13.0, Lifecycle 2.11.0, Room 2.8.5 and DataStore 1.3.0. Compile/target/min remain 37/36/26. Navigation Compose 2.9.5 and bundled Latin OCR 16.0.1 are intentionally retained.

KSP 2.3.10 is retained while its actual compiler/Room pipeline is built; the newly reported KSP 2.3.13 concurrent-execution regression is avoided. Gradle parallel execution is off, one worker and two active processors bound compiler/dex memory pressure in this environment. A first multi-worker Android attempt lost its daemon during dex/test compilation; this is recorded as a resource failure, not a successful check.

The official Gradle wrapper task regenerated scripts/JAR and pins Gradle distribution SHA-256 `bbaeb2fef8710818cf0e261201dab964c572f92b942812df0c3620d62a529a01`. Unix executable mode is preserved. Linux execution and Windows batch execution have distinct status; a Linux build does not certify Windows execution.
