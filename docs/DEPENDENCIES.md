## Runtime and advisory corrections

The first executed API 35 run exposed a serialization mismatch that host assembly did not detect: Android test JSON resolved to 1.8.1 while consistent resolution kept serialization core/BOM at 1.7.3 from the app graph. Room's generated migration serializers then raised `AbstractMethodError` for `typeParametersSerializers()`. An explicit serialization BOM 1.8.1 aligns app and instrumentation graphs. Migration tests remain enabled; runtime verification must pass before the gate changes. The upstream [serialization issue](https://github.com/Kotlin/kotlinx.serialization/issues/2968) and [1.8 change notes](https://github.com/Kotlin/kotlinx.serialization/blob/master/CHANGELOG.md) explain the interface/default-method transition.

The Android regex backend rejects the OpenJDK embedded `(?U)` flag. Explicit letter/number/whitespace classes and boundaries preserve the Python contract on both engines. Six new Unicode/whitespace regressions expand the full pack to 59 cases, and native instrumentation now compares the complete contract directly. [Android Pattern documentation](https://developer.android.com/reference/java/util/regex/Pattern).

A fresh npm advisory query found a moderate development-tooling issue through `typescript-eslint` → `minimatch` 10.2.6. The maintained TypeScript ESLint version was still 8.72.2, so its estree dependency has a scoped override to minimatch 11.0.8. A fresh lock/install resolves all minimatch copies to that version; type checking, lint, unit/parity and production/browser checks verify compatibility. This is not a browser-input inference dependency. The [maintainer advisory](https://github.com/isaacs/minimatch/security/advisories/GHSA-g3hv-75wg-m249) identifies 11.0.1 as patched. The original and corrected audit reports are preserved under `assets/evidence/v2`. No automated forced downgrade was accepted.

The pinned Python requirements audit reports no known advisories in 14 entries. Neither npm nor Python advisory results cover unknown vulnerabilities, Android native SDK internals or application logic. CI lint reported 0 errors / 9 warnings; newer optional versions and the deliberate API 36 target are visible, without globally suppressing warnings.
