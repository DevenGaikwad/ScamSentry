# Actual privacy behavior

ScamSentry does not read the inbox, contacts, notifications or location. Users type, explicitly paste, share text, or choose a screenshot. There is no login, project analytics, remote explanation service, cloud database or model-update service. ML Kit's dependencies include operational-diagnostics/data-transport components; these may retain SDK usage metadata in app-private storage. The project does not provide them message text or screenshots for uploading. The source manifest removes Internet and network-state permissions inherited from dependencies. Merged permissions and observed device/network behavior are separate evidence; no universal SDK-communication guarantee is made.

Draft messages, analysis and screenshot previews live in app memory. They survive rotation within the same ViewModel and are discarded after process death. Editing invalidates an old result. Original screenshots remain wherever the user selected them; the app reads a bounded stream and does not copy source screenshots to storage. Bitmap previews are released on replacement, result, clearing and ViewModel disposal. User mistakes and process memory are not forensically erased.

History is off by default. Enabling it does not save automatically. Saving a summary requires a preview decision and stores a fixed description, risk category, counts, time, input method and model/policy versions. It stores no message body, actual host, full URL, image or free-form annotation. This metadata can still reveal usage; Room is not encrypted and device access controls matter. Saving, deletion and privacy-setting changes are serialized. Disabling history clears its records, and a queued save rechecks the current setting before writing. Clear-all and per-entry deletion are available. Schema v2 adds the input method; its v1→v2 migration preserves old summaries and labels legacy input methods unknown. The instrumentation test and its executed status are recorded separately.

Reports omit original text, destinations, identifiers and screenshots. The exact redacted content is previewed before Android's share chooser. A cache copy is retained until replacement or startup cleanup after 24 hours. Copies exported to other apps are controlled by those apps and are not deleted by clearing ScamSentry history. FileProvider exposes only `cache/exports/` via temporary read grants.

Backup and device-transfer rules exclude the relevant app storage. Manifest settings alone do not prove behavior on every manufacturer; actual restore/transfer checks remain on the device checklist. No forensic secure-erasure claim is made.

ML Kit Latin OCR is bundled (`com.google.mlkit:text-recognition:16.0.1`). No model-download declaration is included. App network permission is removed; a first-install offline/device-network observation is required before a broad offline guarantee is accepted. SDK licensing and notices remain applicable even though images are processed locally.

Training uses a historical publicly licensed corpus, separate from app-user data. Numeric strings, email addresses and URL strings are minimized before features. Automated checks find residual patterns; names and third-party content cannot be eliminated reliably by regular expressions. Raw and processed message tables, private examples and object-pickle files are excluded from distribution. Model vocabularies still derive from text and are not a mathematical privacy guarantee. No user history is ever used for training.
