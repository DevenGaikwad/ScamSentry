# Priorities after the research preview

Browser 0.4.0 is live, and Android 0.3.0-preview provides three verified TEST-signed APKs. The release audit records exact source, public downloads, tests and outstanding device and model validation. [Live app](https://scamsentry-inspect.vercel.app/) · [Release audit](V4_ACCEPTANCE.md)

| Priority | Entry requirement | Exit evidence |
|---|---|---|
| Physical-phone release validation | Owner-controlled Android device and chosen build | Fresh offline text/OCR, share/lifecycle/storage/large-font/TalkBack checks and device timings |
| Deliberate public signing | Owner-managed signing identity outside repository | Signed/minified APK tested independently with checksums and source/model linkage |
| Optional Git-push web deployment | Deliberately install/configure the Vercel GitHub integration and review source-build settings | Automatic deployment from reviewed main with exact commit, public workflow, digest/privacy and no-cost checks; current standalone site remains useful |
| Better obfuscation coverage | New independent training/evaluation protocol | Improvements against separate perturbations and fresh holdout; never retune against the archived test silently |
| Campaign-diverse English data | Compatible recorded rights, reviewed labels and overlap checks | New independent groups, honest source-shift evaluation and improved errors |
| Learned URL module | Lexical availability matrix and domain grouping | Separate calibrated artifact, parity and useful domain-isolated performance |
| Marathi/Hindi/Hinglish | Eligible labelled data and language-specific review | Independent evaluated scope; no inherited English accuracy claim |
| QR from selected image | Complete core device gates | Review-before-analysis, no camera permission dependency, bounded decode tests |
| Usability pilot | Voluntary task protocol | Actual aggregate observations and documented changes |

Account creation, automatic inbox monitoring, cloud sync, paid APIs, remote explanations, website reputation feeds and monetization remain outside the current core.
