# Optional voluntary usability pilot — not yet conducted

Use five short fictional tasks: paste/analyze, correct OCR, identify the actual host, interpret uncertainty and delete a saved summary. Ask volunteers only after explaining the task and minimal anonymous observations. No inbox exports, real messages, participant names or identifiable recording are needed.

Record task completion, errors, time only if measured consistently, confusing wording and whether lower observed risk is mistaken for verified legitimacy. Use the exact app/build version and device condition. Keep any consented notes private; publish aggregate observations and non-identifying summaries only.

A small convenience sample can guide interface revisions. It cannot establish population-wide fraud prevention. No participant count, satisfaction score or study result exists for this preview. Create a revision log only after actual observations.
