# V2 exploratory optimization protocol — frozen before fitting

Protocol `ss-exploratory-v2`, recorded 16 November 2026. The historical final test and perturbation failures have already been seen; they are not a blind test. This experiment does not score that partition. Only existing training, development and calibration membership may influence new fits. No new random holdout is presented as external validation. Mendeley V1 remains the sole eligible source; UCI and permission-dependent sources remain excluded. No private app inputs enter research.

Eight predeclared CPU configurations compare portable word TF–IDF, separately normalized character/word blocks, and character training with bounded synthetic noise. Three StratifiedGroupKFold folds on training groups (seed 42) select the configuration; each fold fits vocabulary, IDF and estimator from that fold's training parents. Synthetic variants are made only after parent splitting, remain with the parent, and include all classes. Augmentation covers partial o→0/l→1 confusions and sparse inserted zero-width spaces. It is a sensitivity experiment, not measured OCR or current-campaign evidence. All originals are retained.

Rank candidates by mean fixed-label macro-F1 among those with mean smishing recall ≥ .80 and ordinary→smishing rate ≤ .03; if none qualify report the constraint failure. Ties within .002 prefer fewer serialized parameters, then shorter fit time. Also report the highest score without constraints. No second search or adaptive grid expansion is planned. Stop at 24 fold fits plus 8 full-training fits; 2 CPU threads, no GPU or paid service. Preserve failed configurations and warnings.

Refit each predeclared configuration on training only. Fit one scalar temperature on calibration only, bounded exp(-2)…exp(2), minimizing three-class log loss. Development is used for final exploratory comparisons, threshold investigation and error slices; it is not independent of historical architecture design. Evaluate clean text, case/spacing invariance, severe all-o/l substitutions and inserted zero-width spaces. Paired group bootstrap (seed 42, 300 replicates) compares development macro-F1. Report supports and broad uncertainty.

Threshold sweeps use confidence {.50,.62,.75,.85}, margin {.05,.18,.30}, and smishing warning thresholds {.20,.35,.50,.65,.80}. Illustrative costs are missed smishing 5, ordinary high warning 1, deferral .25; promotional high warning .5. These are academic assumptions, configurable, and do not estimate financial harm. Keep threshold analysis separate from coefficients/calibration; production thresholds remain .62/.18 until a promotion review. Whole-system scores use reviewed original inputs, while model-only scores use the minimized view. Define accepted as non-`unable`; an abstained positive is an unresolved automatic detection.

Promotion requires a meaningful paired improvement (macro-F1 point gain ≥ .01, positive paired CI lower bound), no decline of smishing recall > .02, ordinary high-warning burden ≤ .03, materially stronger noise results, export/parity checks and actual phone resource measurements. A prospective eligible contemporary holdout is still required for a broader model claim. Without independent validation and phone measurements, retain `ss-char-lr-0.1.0` and publish research candidates separately. No forced promotion or perfect-accuracy claim.

The training environment remains pinned independently of the Android upgrade. Reports include data/split/config digests, group counts, environment, source commit, fit time, process peak RSS, model size, all confusion counts/rates, calibration and selective coverage. Public artifacts contain IDs/aggregates; raw texts and fitted executable objects remain private. Compact neural work is deferred: this linear comparison directly addresses the observed word-model gap with affordable, portable inference.
